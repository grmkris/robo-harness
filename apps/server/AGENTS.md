# @robo/server

The coordinator process. Bun hosts it; it owns the control leases, the ten-hertz sampler, chat runs, decision runs (`src/decision/`: candidates, Jev evaluation adapter with a persistent spend meter, text-only perception, JSONL run logs) and the MCP surface. Chat and decision runs share one motion executor (`src/motion-executor.ts`). It talks to the motors only through the Python I/O service over HTTP, never directly, and decodes every response at that boundary. Imports the value types from `@robo/domain` and the tool schemas from `@robo/protocol`; uses Effect Schema for request-body validation. Tests spawn the real process on port 0 through `test/harness.ts`; add cases there, not fixed ports.
